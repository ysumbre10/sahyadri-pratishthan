# Search visibility

The public site uses unique translated titles/descriptions, canonical URLs, reciprocal Marathi/Hindi/English alternate links, an XML sitemap and organisation/website/page structured data. Fort pages should only be added when a documented project or source supports them.

## After deployment

1. Open the organisation's existing Google Search Console property for `https://sahyadripratishthan.com/`. The ownership verification file remains in the build.
2. Submit `https://sahyadripratishthan.com/sitemap.xml` if not already submitted. Inspect the homepage, `/forts/` and the new guides and request indexing after verifying the deployed pages load.
3. Check Page indexing and Crawl stats for errors. Use Performance to compare impressions, clicks and queries over several weeks, separately for Marathi, Hindi and English pages.
4. Confirm `/favicon.png` and `/favicon.ico` return images, not an HTML error. The PNG is a square 96px crop of the supplied official logo. Keep these URLs stable. Google may take days or weeks to recrawl and does not guarantee displaying a favicon.

## Grow the archive

Add dated campaign reports with the fort name, the exact work done, organiser-approved text, original photographs, relevant permissions and source links. Give each account useful context rather than repeating fort names. Link reports from their fort page. Do not claim work at forts where the organisation has no evidence, fabricate reviews or describe the NGO as “best” without independent support.

For broader Shivaji Maharaj/Swarajya history, commission source-reviewed articles that distinguish historical research from conservation reports. Search visibility depends on relevance, quality, competition and references from other trustworthy sites; no rank or indexing guarantee is implied.
